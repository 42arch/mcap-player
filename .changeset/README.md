# Changesets

Hello and welcome! This folder contains files for Changesets.

## Adding a Changeset

To add a changeset for your modifications, run:

```bash
pnpm changeset
```

Follow the prompts to select bump types (patch/minor/major) and write a summary of the changes.

## Versioning & Updating Changelog

When ready to bump versions and update `CHANGELOG.md`, run:

```bash
pnpm version-packages
```
