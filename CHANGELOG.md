## v1.0.0

### 🚀 Release

- Release v1.0.0 of MCAP Player, a browser-based player and visualization tool for robotics, autonomous driving, and other time-series sensor data
- Open local `.mcap` files or stream remote files from HTTP/HTTPS URLs with HTTP Range requests, without uploading local files
- Decode ROS 1, ROS 2, Protobuf, JSON, and JSON Schema messages, including uncompressed, Zstd, and LZ4 chunks
- Inspect data with summary, raw message, image (including H.264), plot, timeline, 2D map, and 3D scene panels
- Play, pause, seek, step forward or backward, and change playback speed
- Handle large files with Web Workers, block-based reads, and caching
- Group panels, rearrange layouts by dragging, and import or export layouts
- Switch between Simplified Chinese and English, with light, dark, and system themes
